# Sécurité et données

Tous les fichiers sont chiffrés au repos avec l'algorithme AES-256 et les échanges sont protégés par TLS 1.3.

Les serveurs sont hébergés dans l'Union européenne, dans les centres de données de Francfort et de Paris.

L'authentification à deux facteurs est disponible via une application TOTP ou une clé de sécurité FIDO2.

Un fichier supprimé reste récupérable dans la corbeille pendant 30 jours, puis il est définitivement effacé.

L'offre Équipe inclut un journal d'audit des actions des utilisateurs, conservé 90 jours.
